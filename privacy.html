Privacy policy

Effective 21 October 2026

Katha Studio is a personal video tool that runs only on its creator's own computer. This policy explains what it does with information from Google accounts.

What it accesses

When you connect a YouTube channel, Katha Studio asks Google for permission to upload videos to that channel (youtube.upload) and to read the channel's basic details, such as its name and picture (youtube.readonly).

How it uses that access

It uploads only the videos you choose to post, with the title, description, tags and thumbnail you review, and it shows the channel's name so you know where a video will go. It does not read your other videos, comments, subscribers or analytics.

Where your information is kept

The access token Google issues is stored only in a file on the computer where Katha Studio runs. It is not sent to any server other than Google's, and it is never sold, shared, or used for advertising.

Google API Services

Katha Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Katha Studio uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

Removing access

You can disconnect Katha Studio at any time at myaccount.google.com/permissions, or by unlinking the channel in Katha Studio, which deletes the stored token.

Contact

Questions about this policy: open an issue at github.com/urmanhr/katha-studio.
